# Ярмарка тщеславия — остров React

Лента историй над постами главной alterlit.ru: кружки авторов (цвет — по рубрике), девиз при
наведении (на телефоне — долгим нажатием), «+» — разместить свою публикацию с девизом и оплатой.

- Сборка: `npm run build` → `dist/story.js`, `dist/story.css` (статика `/assets/story/`).
- Выкладка: `../deploy.sh story` (с `-b` — с пересборкой).
- Бэк: `django/story/` (пакет `api/story/`), собранный патч — `django/story_patch.py`
  (`python3 tools/build_patch.py` после правок).

## Dev

`npm run dev` → http://localhost:5182/ — настоящая главная с прода (с сессией `DEV_COOKIE`),
в которой старая ярмарка заменена островом. `/sandbox.html` — пустая страница только с островом.

`.env.local` (в git не попадает):

- `BACKEND_URL`, `DEV_COOKIE` — сервер и строка Cookie для прокси;
- `DEV_FIXTURES=1` — истории и свои публикации из `dev-fixtures/`, размещение — заглушка
  (на сервер ничего не уходит);
- `FIXTURE_AS=guest|staff`, `FIXTURE_DENY=1` — гость, администратор (бесплатно), размещение недоступно.
